# 潮词 · Tidelrc


Tidelrc themed lyric timing studio. Forked from [magic-akari/lrc-maker](https://github.com/magic-akari/lrc-maker) (MIT) and restyled as **潮词**.

## Use

```bash
pnpm i
pnpm start
```

```bash
pnpm build
```

Vercel: Framework Vite, Output `build`, Install `pnpm i`, Build `pnpm build`.
